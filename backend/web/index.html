1. Authenticate

No login flow exists yet — mint a dev token from a terminal in the repo: python scripts/create_dev_user.py you@example.com, then paste it below. It's saved in this browser only (localStorage), never sent anywhere but this API.

2. Submit a VOD

Options (model, clip count, length, score bar)

Longer videos on slower/CPU-only machines: pick tiny to cut transcription time substantially at some accuracy cost. Short videos, or accuracy matters most: small or up. See README's "Job timeouts" section for how this trades off against processing time.

Leave any field blank to use the project default. "Min score" filters out low-scoring candidates even if fewer than "Max clips" clear the bar -- see the score shown on each clip below.

Pick what the VOD actually looks like -- this is the single biggest lever on whether a clip frames the right thing.
IRL / just chatting / webcam: one crop that follows the person. Use whenever the speaker is the subject.
Gameplay or screen + facecam: splits the clip -- a zoom on the webcam box on top, the gameplay below. Only use when there really is a small webcam overlay.
Show the whole frame: crops nothing; the full 16:9 picture is scaled to fit the width over a blurred background. Best for gameplay/screen share where a vertical crop cuts away the part that matters. Trade-off: a smaller picture.
Auto guesses per clip from a detected face's size and position. It was previously far too eager to split (it treated 96% of face positions as "a corner webcam"); that was fixed on 2026-09-11, but an explicit choice still beats a guess when you know the VOD.
"Crop side" only applies to the layouts that crop, and overrides face-following when set -- useful when the important content consistently sits on one side of your layout.
